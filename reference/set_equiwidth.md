# Set a global equiwidth

Set a global default for the `equiwidth` argument used by
[`get_width()`](https://davidhodge931.github.io/ggwidth/reference/get_width.md).

## Usage

``` r
set_equiwidth(equiwidth = 1)
```

## Arguments

- equiwidth:

  A single positive finite numeric value.

## Value

The previous option value, invisibly.
